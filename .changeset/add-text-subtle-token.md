Add a `textSubtle` color token (`#8B8B8B`, identical in light and dark, both brands). It sits between `textMuted` light (`#666`) and dark (`#AAA`), and replaces the scattered one-off mid-greys (`#808080`, `#888`, `#999`) found across the apps. Intended for decorative or non-text UI such as muted icons and inactive indicators (about 3.4:1 on white), not for body text — use `textMuted` for that.
